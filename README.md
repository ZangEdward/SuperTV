# SuperTV 📺

一个基于 Flutter 构建的高性能视频播放器，旨在提供流畅的跨平台视频观看体验。本项目由 [zimplexing/oriontv](https://github.com/zimplexing/oriontv)基于[MoonTechLab/
Selene](https://github.com/MoonTechLab/Selene) 启发并演进。

## ✨ 功能特性

- **现代化 UI**: 简洁美观的界面，采用 Material 3 设计语言，适配手机、平板和电视。
  - **TV 模式自适应**: 
    - **智能识别**: 自动识别 Android TV/Fire TV 等电视设备及遥控器 D-pad 导航模式，无需手动开启即可进入电视 UI。
    - **专用 TV 主界面**: 侧边导航设计，专为电视遥控器 D-pad 优化，支持流畅的焦点切换。
    - **TV 专用搜索**: 3 栏式设计，包含拼音首字母键盘（A-Z, 0-9）及智能搜索建议，大幅提升电视端输入效率。
    - **TV 专用播放器**: 大尺寸控件，支持遥控器快速选集、换源及播放控制，自动隐藏界面。
  - **顶栏优化**: 移除了冗余的大标题，引入沉浸式搜索框，使界面更加协调、高效。
  - **主题切换**: 支持深浅模式平滑渐变切换，告别突兀的视觉跳变。
- **缓存下载**: 
  - **多线程下载**: 借鉴高性能下载技术，支持 M3U8 视频片段的多线程并发下载（单集并发数基于 CPU 核心数动态调整，默认 10 线程）。
  - **任务队列管理**: 智能下载队列，支持设置同时下载的剧集数量（1-10 集，默认 5 集），自动调度并严格控制并发任务。
  - **断点续传**: 实时监测本地已下载片段，支持在应用重启或网络中断后精准续传，无需重复下载。
  - **缓存多线程解密**: 针对 AES-128 加密流，将 CPU 密集型的解密任务从主线程剥离，利用多核 CPU（Isolate）并行处理，极大提升了加密资源的下载与保存速度。
  - **自动合并清理**: 下载完成后自动将所有片段合并为单个 TS 文件，并智能清理临时片段。
  - **真实文件清理**: 删除缓存任务时，同步清理本地已下载的 TS 文件及临时目录，节省存储空间。
  - **全局控制**: 缓存管理页面集成“全部暂停”与“全部恢复”功能，一键管理所有任务。
  - **任务持久化**: 基于 SharedPreferences 的任务管理，支持断点续存与状态自动恢复。
  - **多选缓存**: 播放页下载面板支持多集选择、全选/反选，并实时显示剧集的缓存状态（已下载/排队中）。
  - **下载中心**: 顶部导航集成下载中心，提供任务列表、进度追踪、暂停/删除等管理功能。
- **界面优化**:
  - **全场景暗黑模式**: 登录页等核心页面已完成全深色模式适配，提供沉浸式且保护视力的视觉体验。
  - **沉浸式搜索**: 搜索界面 header 优化，移除冗余控制按钮，使搜索体验更纯粹；引入网盘搜入口，一键直达全网资源。
  - **视频详情菜单 (VideoMenuBottomSheet) 深度重构**:
    - **二段式交互**: 引入类似原生 iOS 的二段式滑动关闭逻辑，支持从最大高度收起到初始高度，再从初始高度向下拖拽关闭的丝滑过渡。
    - **智能数据加载**: 集成豆瓣 (Douban) 与 Bangumi 详情 API，自动异步加载剧情简介、演职人员、评分及分类等丰富信息，并支持长按呼出。
    - **异步资源处理**: 优化了封面图加载逻辑，采用并发机制同步获取图片 URL 与防盗链 Headers，彻底解决部分来源封面因反盗链导致的无法显示或加载缓慢问题。
    - **自定义滚动物理**: 针对展开状态开发了 `CollapsibleScrollPhysics`，智能识别顶部向下拖拽的收起意图，提供更符合直觉的交互反馈。
    - **性能优化**: 优化了 `FutureBuilder` 的数据处理流程与 `setState` 触发频率，确保在高度拖动与数据加载时的 UI 流畅度。
- **匹配增强**: 
  - **去尾模糊匹配**: 针对标签页（如番剧）进入的剧集，若精确匹配失败，将自动尝试“去除最后一个空格”后的标题进行模糊匹配，大幅提升资源搜索成功率。
- **缓存管理与清理**:
  - **清除缓冲数据**: 个人菜单新增“清除缓冲数据”，一键清理豆瓣/Bangumi 缓存、内存缓存及系统临时文件（播放器缓存/图片缓存），同时确保已下载视频不受影响。
- **网盘搜**:
  - **多平台资源**: 深度集成网盘资源搜索，涵盖夸克、阿里、百度、磁力、迅雷等主流平台。
  - **便捷操作**: 搜索结果支持一键复制链接或直接打开浏览器跳转，快速获取资源。
- **动态动画**: 
  - **标签切换**: 采用现代化卡片式缩放（Scale）与淡入淡出（Fade）动画，取代传统滑动，增强界面层次与深度感。
  - **主题切换**: 支持深浅模式平滑渐变切换（基于 AnimatedTheme），提供更细腻的视觉过渡效果。
  - **搜索体验**: 搜索界面支持灵动的顶部滑入与滑出效果；搜索框提示文字支持自动截断，适配各种屏幕尺寸。
- **Bangumi 增强**:
  - **全方位数据代理**: 个人菜单中新增 Bangumi 数据源与图片源切换功能。数据源支持“客户端直连”、“服务端转发”、“反向代理”；图片源支持“直连”、“服务器代理”，确保番剧数据与封面的访问体验。
  - **智能路由**: 代理模式仅作用于 Bangumi 相关接口，与豆瓣（Douban）及其他视频源的独立设置互不干扰，实现精准的网络优化。
- **登录优化**: 
  - **智能节点**: 登录界面集成服务器节点下拉选择框，支持通过环境变量 `API_NODES_JSON` 动态注入多个后端入口。
  - **深度主题适配**: 登录界面已完成全场景深浅模式适配，支持随系统主题实时、平滑切换。优化了表单填充色、光标及交互提示，确保在 Android 等各平台上的视觉连贯性。
  - **Web Demo 绕过**: 针对 Web 展示环境优化，在浏览器端自动跳过后端登录验证及订阅内容连通性检查，确保护送演示流程顺畅。
- **构建修复**:
  - **跨平台兼容**: 修复了 Windows 标题栏组件的调用冲突，并优化了多线程下载服务的内部引用，提升了代码的稳健性与编译成功率。
- **跨平台支持**: 支持 Android (com.supertv.app)、iOS、macOS 和 Windows。
- **原生体验**: 全面优化按钮样式与交互反馈，提供接近原生的使用感受。
- **节点切换**: 支持多 API 节点智能选择，确保连接稳定性。

## 🚀 快速开始

### 1. 配置服务器节点

应用支持通过构建时注入 `API_NODES_JSON` 来配置下拉选择的服务器节点。

格式如下：
```json
[
  { "key": "node1", "label": "服务器A", "url": "https://api.example.com" },
  { "key": "node2", "label": "服务器B", "url": "https://api.backup.com" }
]
```

### 2. GitHub Actions 配置 (Secrets)

为了实现自动化构建，请在 GitHub 仓库的 `Settings -> Secrets and variables -> Actions` 中添加 `APP_SECRETS`。

`APP_SECRETS` 的内容应为如下 JSON 格式：

```json
{
  "api_nodes_json": "[{\"key\": \"node1\", \"label\": \"服务器A\", \"url\": \"https://api.example.com\"}]",
  "key_alias": "YOUR_KEY_ALIAS",
  "key_password": "YOUR_KEY_PASSWORD",
  "signing_key": "YOUR_BASE64_ENCODED_JKS_FILE",
  "pat": "YOUR_GITHUB_PERSONAL_ACCESS_TOKEN",
  "source_repo": "YourUsername/SuperTV",
  "sync_repo": "YourUsername/ota-sync-repo"
}
```

> [!TIP]
> `signing_key` 是你的 Android 签名文件 (.jks) 的 Base64 编码字符串。可以使用命令 `base64 -w 0 your-key.jks` 生成。

### 3. 本地编译

如果你想在本地编译，可以运行：

```bash
flutter build apk --release --dart-define=API_NODES_JSON='[{"key":"local","label":"测试","url":"https://test.com"}]'
```

## 🛠️ 技术栈

- **框架**: Flutter 3.24.x
- **状态管理**: Provider
- **网络请求**: Dio, Http
- **播放引擎**: Media Kit
- **持久化**: SharedPreferences
